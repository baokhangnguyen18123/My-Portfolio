## 🌟 Tính năng & Điểm nhấn Thiết kế (Design Skills)

- **Neo-Glass Bento Grid Architecture:** Bố cục dạng khối Bento hiện đại, tối ưu thị giác, thẻ kính mờ (`backdrop-filter: blur(20px)`), viền phát sáng gradient tinh tế.
- **Interactive Constellation Canvas:** Hiệu ứng mạng lưới hạt chuyển động mượt mà phản hồi theo tọa độ chuột ở Hero section.
- **Bilingual Support (Song ngữ VI / EN):** Chuyển đổi ngôn ngữ tức thì với toàn bộ nội dung, siêu dữ liệu SEO và nhãn trợ năng.
- **Dark / Light Luxury Themes:** Chế độ tối không gian sâu (mặc định) với điểm nhấn ngọc lục bảo (Emerald) & Cyan, kết hợp chế độ sáng gốm sứ thanh lịch.
- **Dynamic Role Cycler:** Hiển thị luân phiên các chuyên môn chính (.NET Developer, Business Analyst, Data Specialist, Applied AI).
- **Interactive Delivery Pipeline:** Khám phá quy trình 4 bước (Phân tích, Thiết kế, Xây dựng, Đo lường) kèm công cụ & sản phẩm bàn giao thực tế.
- **Filterable Skill Matrix:** Lọc năng lực theo từng nhóm chuyên môn (Software, Data & BI, Applied AI, Tools & DevOps) kèm thanh tìm kiếm thời gian thực.
- **Interactive Case Study Deep Dives:** Xem trước các dự án nổi bật (`stockfarm-erp`, `Knowledge Cube AI`, `Supply Chain Analytics`) với modal phân tích bài toán, kiến trúc, đóng góp và công nghệ.
- **Tactile Contact Deck & Confetti:** Nút sao chép email 1-chạm kèm hiệu ứng pháo hoa chúc mừng (confetti), đồng hồ thời gian thực TP.HCM (ICT) và mẫu tin nhắn tuyển dụng soạn sẵn.

## 🛠️ Công nghệ Sử dụng (Tech Stack)

- **Frontend Core:** [React 18](https://react.dev/) + [Vite 5](https://vitejs.dev/)
- **Styling:** Vanilla CSS3 Design System (CSS Tokens, HSL & Gradient tailoring, Keyframe micro-animations, Glassmorphism, CSS Grid & Flexbox)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Micro-effects:** [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) & HTML5 Canvas API
- **Deployment:** GitHub Pages với GitHub Actions CI/CD (`.github/workflows/deploy.yml`)

---

## 🚀 Khởi chạy trên máy cục bộ (Local Development)

### Yêu cầu môi trường
- Node.js `18.18+` hoặc `20+`
- npm `9+`

### Cài đặt và chạy
```bash
# 1. Cài đặt các gói phụ thuộc
npm install

# 2. Khởi chạy máy chủ phát triển
npm run dev

# 3. Đóng gói cho production
npm run build

# 4. Xem trước bản build
npm run preview
```
