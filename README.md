# Nguyen Bao Khang - Portfolio

Website portfolio ca nhan dang static, gioi thieu thong tin, ky nang, du an, hoc van va CV cho vi tri Business Analyst/.NET Developer. Giao dien ho tro song ngu, responsive, light/dark theme va reveal animation khi cuon trang.

## Cong nghe

- HTML5
- SCSS (Dart Sass)
- Vanilla JavaScript voi ES Modules
- Node.js cho local development server

Khong su dung frontend framework hay thu vien animation.

## Phien ban

- Portfolio: `1.0.0`
- Dart Sass: `1.102.0`
- Moi truong da kiem tra: Node.js `18.18.2`, npm `9.8.1`
